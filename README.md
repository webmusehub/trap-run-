# TRAP RUN

> **RUN. JUMP. TRUST NOTHING.**

Trap Run is a deadly 2D browser platformer built with TypeScript, HTML5 Canvas, and Web Audio API. Speedrun through 10 handcrafted levels filled with hidden spikes, falling platforms, moving hazards, and fake exits to claim your rank on the global leaderboard!

---

## 🎮 Features

- **10 Handcrafted Levels**: From the Dungeon Entrance to The Final Run gauntlet.
- **Global & Level Leaderboards**: Online leaderboards powered by Supabase Edge Functions & PostgreSQL.
- **Server-Side Anti-Cheat**: Physical minimum completion times, coin caps, and run lifecycle verification.
- **Dynamic Physics & Feel**: Jump buffering, coyote time, screen shake, and object-pooled particle bursts.
- **Desktop & Mobile Controls**: Keyboard navigation (`A`/`D`/`W`/`Space`/`Esc`/`R`) and responsive touch overlay for mobile devices.
- **100% Offline & Network Resilient**: Fallback local progression if network or backend is unavailable.
- **Web Audio API**: Dynamic chiptune music and sound synthesis.
- **Monetization & Analytics Ready**: Non-intrusive ad placement hooks and 17 non-blocking event tracking handlers.

## 🚀 Quick Start

### 1. Installation

```bash
git clone https://github.com/webmusehub/trap-run-.git
cd trap-run-
npm install
```

### 2. Development Server

```bash
npm run dev
```

### 3. Run Tests

```bash
npm test
```

### 4. Production Build

```bash
npm run build
```

## 🛠️ Technology Stack

- **Language**: TypeScript
- **Renderer**: HTML5 Canvas 2D
- **Build Tool**: Vite
- **Testing**: Vitest
- **Backend**: Supabase (Edge Functions & PostgreSQL)
- **Styling**: Vanilla CSS (Responsive & Pixel-Art Aesthetic)
